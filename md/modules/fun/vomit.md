## Vomit

Vomit throws the items in your inventory onto the ground one by one, in random order. When your inventory is empty and a chest is open, it throws out the chest's items. In Creative mode it throws random blocks forever.

**Category:** Fun
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| Constraints | Setting Group |  |  | How fast items are thrown. See [Shared: Inventory Constraints](/docs/modules/shared-settings/inventory-constraints). |
