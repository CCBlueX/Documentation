## HandDerp

HandDerp keeps switching your main hand between left and right, so other players see your item jump from hand to hand. When you turn it off, your hand goes back to how it was.

**Category:** Fun
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| Silent | Toggle | false |  | Other players still see the switching, but you don't. |
| Mode | Mode Selector | Delay | Delay, Swing | Delay: switches hands on a timer. Swing: switches every time you hit. |
| Mode → Delay → Delay | Integer | 1 | 0..20 ticks | How long to wait between switches, in ticks (20 per second). |
