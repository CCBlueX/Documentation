## NoSlotSet

NoSlotSet stops the server from changing which hotbar slot you hold. When a server tries to switch your slot, the client ignores it and tells the server the slot you actually have selected.

**Category:** Player
**Enabled by default:** No

### Settings

This module has no settings.
