## CombineMobs

CombineMobs draws only one mob when many mobs of the same kind stand in the same spot, and shows how many there are. This makes big mob piles easier to look at and can help your FPS. Babies and adults are counted separately.

**Category:** Render
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| CombineArmorStands | Toggle | false | | Also combines armor stands. |
| CombineMinecarts | Toggle | false | | Also combines minecarts. |
