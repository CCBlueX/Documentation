## SilentHotbar

Some modules, like [KillAura](/docs/modules/combat/killaura) or [Scaffold](/docs/modules/world/scaffold), switch to another hotbar slot for a moment without you selecting it. SilentHotbar keeps showing the item you picked in your hand while that happens.

**Category:** Render
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| NoCooldownProgress | Toggle | true | | Also hides the attack cooldown of the item the module switched to. |
