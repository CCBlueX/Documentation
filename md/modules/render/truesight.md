## TrueSight

TrueSight shows things that are normally invisible: barrier blocks, light blocks and invisible players or mobs. It helps you find hidden walls on a map or spot someone using an Invisibility potion.

**Category:** Render
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| Sight | Multi-Select | Barriers, Lights, Entities | Barriers, Lights, Entities | What to show: barrier blocks, light blocks and invisible entities. |
| EntityColor | Color | White, alpha 100 | | Color of invisible entities. Lower the alpha to make them more see-through. |
| EntityFeatureLayerColor | Color | White, alpha 120 | | Color of the extra layers on invisible entities, like armor. |
