## NoSwing

NoSwing stops the hand swing animation that plays when you hit, use an item or click a block.

**Category:** Render
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| HideFor | Multi-Select | Client, Server | Client, Server | **Client** hides the swing on your own screen. **Server** stops telling the server you swung, so other players don't see it either. |
