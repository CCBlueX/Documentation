## NameProtect

NameProtect hides your name on your own screen and shows other text instead, in chat, above heads and in the tab list. This is useful when you record or stream. It can also hide the names of your friends and of other players. Other players on the server still see the real names.

**Category:** Misc
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| Replacement | Text | You | | Text shown instead of your name. |
| ColorMode | Mode Selector | Static | Static, Rainbow | Color of your new name. |
| ColorMode → [Static] → Color | Color | | | The color when ColorMode is Static. |
| ObfuscateFriends | Toggleable Group | On | | Hides your friends' names. They show their friend alias, or a made-up name. |
| ObfuscateFriends → ColorMode | Mode Selector | Static | Static, Rainbow | Color of your friends' new names. |
| ObfuscateFriends → ColorMode → [Static] → Color | Color | | | The color when ColorMode is Static. |
| ObfuscateOthers | Toggleable Group | Off | | Gives all other players made-up names. |
| ObfuscateOthers → ColorMode | Mode Selector | Static | Static, Rainbow | Color of other players' new names. |
| ObfuscateOthers → ColorMode → [Static] → Color | Color | | | The color when ColorMode is Static. |
