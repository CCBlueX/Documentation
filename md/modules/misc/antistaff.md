## AntiStaff

AntiStaff warns you in chat and with a notification when a staff member of the server joins your game. It uses a list of staff names for each server. If there is no list for the server you play on, you get a notice and no warnings.

**Category:** Misc
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| ShowInTabList | Toggle | true | | Marks staff members in the tab list. |
