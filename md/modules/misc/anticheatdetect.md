## AntiCheatDetect

AntiCheatDetect guesses which anti-cheat the server uses and tells you in chat, for example `Detected Intave AntiCheat (99% certainty).` The guess can be wrong, mostly on servers with more than one anti-cheat. If it can't tell, it says nothing.

It only tells you. It does not change how anything works.

**Category:** Misc
**Enabled by default:** No

### Settings

This module has no settings.
