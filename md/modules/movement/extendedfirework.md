## ExtendedFirework

ExtendedFirework makes firework rockets push you faster while you fly with an elytra. Big boosts are easy for anti-cheats to spot, so raise them slowly.

**Category:** Movement
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| Mode | Mode Selector | Normal | Normal, Custom | Normal uses a fixed boost of (0.1, 1.65, 0.5). Custom lets you set your own. |
| Mode → [Custom] → VelocityMultiplier | Vector | (0.1, 1.65, 0.5) |  | Extra boost on each axis (X, Y, Z). |
