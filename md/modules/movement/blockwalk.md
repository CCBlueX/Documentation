## BlockWalk

BlockWalk lets you walk on top of blocks you would normally sink into or get stuck in, like cobwebs and snow. The blocks act like full, solid blocks for you.

**Category:** Movement
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| Blocks | Registry List | Cobweb, Snow |  | The blocks you can walk on top of. |
