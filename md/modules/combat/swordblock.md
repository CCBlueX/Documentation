## SwordBlock

SwordBlock lets you block with a sword like in Minecraft 1.8 when you play on a server that uses ViaVersion. Hold use (right click) with a sword to block and take less damage. You can also turn on only the look of blocking.

**Category:** Combat
**Enabled by default:** No

### Settings

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| OnlyVisual | Toggle | false | | Only shows the blocking animation. The server does not see you block. |
| FakeOnPressing | Toggle | false | | Shows the blocking animation whenever you hold the use key with a sword. |
| HideShieldSlot | Toggle | false | | Hides the shield in your offhand while you hold a sword. |
| ApplyToThirdPersonView | Toggle | true | | Also shows the blocking animation in third person view. |
| AlwaysHideShield | Toggle | false | | Hides the shield in your offhand no matter what you hold. |
